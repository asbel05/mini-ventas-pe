# ERP de ventas

Proyecto para registrar pedidos, emitir boletas y facturas simuladas, cobrar con varios medios y gestionar despachos con guías de remisión.

**Stack** · .NET 10, ASP.NET Core MVC con Razor, Bootstrap 5.3, JavaScript nativo, ADO.NET y SQL Server Developer en Docker.

**Estado** · Diseño definido. Implementación pendiente.
